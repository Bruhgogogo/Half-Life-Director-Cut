# Half-Life: Director's Cut

An unofficial enhancement mod for Half-Life 1. Restores cut content, expands lore-accurate elements, and adds quality-of-life improvements while preserving the original game's vision.

---

## Requirements

- Half-Life 1 (any official distribution)
- GoldSrc engine base

---

## Development Notes

Portions of this project were developed with AI-assisted tools. All AI-generated code has been manually reviewed, tested, and integrated by the author.
